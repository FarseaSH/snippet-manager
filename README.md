# Snippet Manager

一个基于 Markdown 的个人代码片段浏览器。React + TypeScript + Vite；公开静态部署；支持全库搜索、四种复制、移动端导航和 PWA 离线使用。

## 开始使用

使用 Node.js 24 或更高版本：

```bash
npm ci
npm run dev
```

打开 http://127.0.0.1:5173 。修改、添加、删除 `snippets/` 中的文件，页面会自动更新，无需先生成 JSON 或构建生产数据。开发模式不注册 Service Worker。

开发依赖会预构建并缓存，首次启动或依赖、相关配置变化后需要重新生成；普通重启会复用缓存。首屏常用模块在服务启动时预热，日期选择器及其样式仅在出现日期参数时加载。图标通过 `src/vendor/` 中的两个入口按实际使用范围预构建，新增界面或品牌图标时同步添加对应导出；`package.json` 的图标子路径供 Node 解析器和前端共用，Vite 中的同名别名用于预构建这些入口。品牌图标的开发 source map 不内嵌完整图标目录源码，其他依赖和应用源码的调试方式不变。

## 项目目录

```text
docs/            编写规范与项目文档
snippets/        内容源与 _folders.yml
scripts/         共用解析器、开发读取、发布构建
src/             React 界面、搜索逻辑与 PWA 通信
public/icons/    应用安装图标
tests/           内容、搜索与浏览器测试
dist/            自动生成的生产产物
```

## 编写内容

完整的文件约定、可复制模板和注意事项见 [Snippet 格式规范](docs/Snippet格式规范.md)。

除普通代码片段外，还支持 `snippet_type: transform` 转换类型：左侧输入、右侧输出，停止输入约 500ms 后执行本地 JS 转换函数；第二个 Tab 可查看转换源码。函数可返回 `language` 指定输出高亮，Markdown 默认预览并支持代码块复制。支持校验提示、异步结果、超时终止和离线运行，示例见 [JSON 格式化转换](docs/examples/transform-json.md) 和 [Markdown 输出](docs/examples/transform-json-to-markdown.md)。

占位符参数和转换左侧输入会保存在当前浏览器的 IndexedDB，刷新、切换片段或重新打开 PWA 后恢复实际填写值；灰色默认值保持默认状态。参数按 Tab 独立保存，“重置参数”只清除当前 Tab 历史；转换“清空”会保存为空，恢复输入后使用当前函数重新生成输出。历史在后台读取，失败或超过约 1 秒则保持初始状态，输入与复制始终可用；读取失败不会用空状态覆盖已有记录。记录按站点路径隔离，不跨浏览器、设备或端口同步。

````markdown
---
snippet_name: 我的片段
snippet_tags: [python, example]
---

整个文件的说明。

# Hello

这段代码的介绍。

```python
print("hello")
```

这段代码的补充说明。
````

- 每个顶层 fenced code block 生成一个 Sub Snippet；多个子片段通过 Tab 切换，只有一个时直接显示代码；一级标题只命名其后、下一个一级标题前的第一个代码块。
- 没有标题的代码块使用 `Untitled`，后续自动编号。
- 说明中的列表、引用内代码块与缩进代码保留原结构。
- 只有一个代码块时保留全部说明，省略摘要列表和 Tab 栏；没有代码块也可正常阅读。
- 当前代码的语言、只读状态、行数和“复制当前代码”按钮位于编辑器下方，归属于当前 Tab 并保持在代码区底部；切换子片段时同步更新，没有代码时不显示状态栏。
- 编辑器采用 Tomorrow 浅色主题，行号区增加左侧留白，状态栏与代码共用圆角容器。编辑器高度由详情页剩余空间动态决定，不设置固定高度，也不按代码行数改变高度；状态栏保持在详情页底部，两侧及底部保留页边距。长代码在代码区内滚动，长说明展开时在说明框内滚动，窗口缩放和说明展开、收起时编辑器同步伸缩。
- Tab、说明和底部状态栏按代码块的语言标记显示对应图标，支持 `py`、`js`、`ts`、`sh` 等别名；Bash / Shell 使用自绘的纯 `$_` SVG 图标，Batch（`bat`、`batch`、`cmd`）使用 [Lucide Terminal](https://lucide.dev/icons/terminal) 平面图标，其他语言 Logo 来自 [Simple Icons](https://github.com/simple-icons/simple-icons)。未知或缺失类型使用通用代码图标，语言 Logo 保留各自品牌色，普通文件夹沿用灰色图标；所有图标随应用打包，可离线显示。
- 元数据错误的文件会跳过，控制台显示路径和原因，其他文件继续处理。
- 相对 `.md` 链接指向库内页面；本地图片随内容一起构建和缓存。
- `.pj/` 不作为内容源。示例内容可以替换为自己的代码库。

Folder 的真实目录决定分类，目录名称保留原始大小写、下划线和连字符，不进行标题格式转换；`_folders.yml` 可设置目录顺序和图标；中栏递归显示选中目录及所有子目录的片段，按名称排序。列表路径及目录入口使用对应文件夹图标，路径显示在名称上方，仅预览主说明，最多一行，超出显示省略号；没有主说明时省略这一行，不使用子片段标题或说明补充；搜索结果也遵循这一规则，不展示代码。

从全部片段或父目录打开 Snippet 时，保留原列表范围、顺序与目录选择，只更新选中项和右侧详情；连续打开其他片段、浏览器前进后退及刷新时仍保留来源目录。清空搜索后恢复搜索前的目录范围，手机端返回同样回到来源列表。直接打开片段链接、没有来源目录时，使用该片段所属目录。

桌面没有全宽顶栏：品牌放在左侧文件夹栏顶部，搜索放在中间列表栏顶部。手机端保留紧凑的搜索与返回入口，搜索词在列表与详情间切换时保留。

宽屏中栏不重复显示目录标题与路径栏；隐藏左侧文件夹栏的窄屏布局通过当前路径按钮选择目录，根目录显示“内容库根目录”。搜索时保留搜索结果标题与数量。

代码页说明默认显示约 5 行，长内容底部以渐变毛玻璃提示更多内容，单击说明框展开，展开后只能通过底部“收起”按钮折叠；短说明完整显示。链接、子片段跳转与文字选择不触发折叠，键盘 Enter / Space 也可切换，切换 Tab 保持展开状态。子 Snippet 说明使用纯语言 Logo 代替圆点，无外框或折角，Logo 根据各代码块语言显示（如 Python、JavaScript），未知类型使用默认代码符号；名称采用普通字体，不使用行内代码的填充样式，不自动插入分隔线，名称与说明链接不显示下划线；Logo 和名称属于同一按钮，共享悬停效果与键盘焦点，点击任意一处都切换到对应 Tab。

```yaml
folders:
  - python[python]:
      - http
      - files:
          - json[json]
  - git
  - linux[bash]
```

`folders` 每项写真实目录名，末尾可加 `[语言标记]` 指定图标，例如 `python[python]`、`linux[sh]`；有子目录时在名称后加 `:` 并嵌套数组。标记不带 `.`，支持 `py`、`js`、`sh` 等别名。子目录继承最近父目录的图标，也可以单独指定；未配置时统一显示普通文件夹图标。中括号不属于实际目录名或显示名称。不存在的目录、无效标记或类型只产生警告，不影响有效内容、排序和其他配置；保存后开发页面实时更新。

桌面和平板代码区使用 CodeMirror 6，提供等宽字体、行号、按需加载的语言高亮、缩进参考线、括号匹配、代码折叠及编辑器内查找（Ctrl / ⌘ + F）。普通片段、转换源码和输出只读，转换输入支持编辑、撤销与重做；所有代码区支持准确选择和复制。占位符更新使用局部事务，保留选区、折叠和滚动位置，全屏和 Markdown 预览切换沿用现有行为。语言使用原生语法解析器或兼容模式；兼容模式和纯文本提供基于缩进的折叠，未知语言按纯文本展示。手机与触摸设备保留只读高亮展示和转换输入文本框，编辑器加载失败时也使用此降级方式。编辑器及语言模块随应用本地打包并进入 PWA 全量缓存，不依赖 CDN；转换函数的隔离执行 Worker 独立保留。

## 阅读与复制

- HTML 代码块支持默认交互预览、源码切换、复制 HTML、重新运行和展开阅读。同组 Tab 使用文件名（如 `index.html`、`assets/style.css`、`assets/main.js`）及标准相对引用，支持 CSS `@import`、JS 模块与 CDN；各 HTML 页在切换 Tab 后保留状态，相关占位符变化约 500ms 后重跑。示例见 [HTML 多文件预览](docs/examples/html-preview.md)，完整规则见格式规范第 9 节。

- Markdown（`markdown` / `md`）代码块默认显示渲染预览，支持标题、列表、任务清单、引用、表格、链接、图片，以及带行号和语言 Logo 的内嵌代码块。原始 HTML 按文本处理，链接经过安全过滤。
- Markdown 参数输入停止约 250ms 后更新预览，等待期间保留上次内容和滚动位置，新内容准备好后直接替换。首次没有可用预览且等待超过约 300ms 才显示加载提示。底栏复制使用最新源码，内嵌代码块复制当前可见版本；转换输出的 Markdown 同样保留成功预览，校验失败或清空输入时清除结果。
- Markdown 预览内的 `html` / `htm` / `html5` 代码块默认显示独立预览，顶部“预览”按钮以淡橙色表示激活，点击关闭后显示代码，支持复制、重新运行和全屏。仅运行当前块的 HTML、内联样式与脚本，支持远程 CDN，不读取其它 Tab 或 snippet；转换输出的 Markdown 也适用。用例见 [Markdown 内嵌 HTML 预览](docs/examples/markdown-html-preview.md)，库内测试放在 `snippets/开发测试snippet/guides/markdown-html-preview.md`。
- 预览使用浅灰色窗口外壳和红黄绿装饰圆点；底栏语言类型左侧的按钮切换预览与源码，两种模式分别保留阅读位置。源码恢复普通 Tomorrow 编辑器样式。
- 预览内每个代码块右上角可单独复制，成功后显示绿色对勾；预览底栏的“复制 Markdown”复制当前代码块的完整 Markdown 原文。页面顶部同名按钮复制整个 snippet 源文件（含 Front Matter）。
- 描述与 Markdown 预览中的行内代码支持 `⌘ / Ctrl + 左键` 复制；普通状态保持紧凑，不预留图标空间，Markdown 预览使用无边框灰色填充。按住修饰键才显示橙色文字、尾部 Copy 图标及相应间距，背景统一为说明区域的淡橙色，hover 时加深为深橙色半粗体。松键后恢复原有宽度和背景，图标不进入复制内容；成功后在上方显示局部提示。
- 只读代码区按住 `Ctrl`（Mac 为 `⌘`）显示淡橙色模糊遮罩，左键单击即可复制整段代码；Markdown 预览中的独立代码块及 HTML 块源码模式同样支持，工具栏和 HTML 实际预览保留交互。代码块复制当前可见预览版本，包括空白和屏幕外内容；长代码的提示位于可见区域。转换输入框不启用，普通选择和查找不受影响。
- 复制等操作的全局消息气泡在代码正文栏内水平居中，分栏调整时跟随，纵向仍位于底部；没有正文时回退窗口居中。输入框保留鼠标和键盘聚焦反馈，其他控件取消额外焦点装饰，保留业务选中状态及键盘功能。
- 桌面左侧活动栏宽度为 48px；文件夹列表与 Snippet 列表使用相同的细滚动条（Chromium / WebKit 为 4px），滚动时显示，停止约 1 秒后以 350ms 动画淡出，两栏分别计时。
- 编辑器右上角按钮可将当前代码或预览铺满右侧正文区，左侧目录与列表仍可使用。`Ctrl + Shift + F` 切换全屏，再按一次退出；也支持 `⌘ + Shift + F`。快捷键适用于代码、Markdown / HTML 预览、转换输出与转换源码，在 HTML iframe 内同样可用。按 Esc 或点击恢复按钮也可退出，保留代码滚动、折叠和预览状态。
- 转换输入框也支持放大，首行保留输入语言、填入示例和清空，底部显示转换状态及错误。转换 Tab 的全屏快捷键作用于当前激活的输入或输出区域；点击区域外后默认放大输入，已经放大时再次按键退出。编辑器查找框打开时 Esc 优先关闭查找。
- 所有代码框共用一个全局自动换行状态，默认关闭；关闭时图标为灰色，激活时使用项目橙色 `#c2410c`，hover 保留灰色填充。普通代码的换行开关位于放大按钮左侧，Markdown 内嵌代码块位于复制按钮左侧。续行不重复编号，选区和空白标记随显示片段对齐，复制与转换仍使用原文。任意按钮切换后，所有 snippet、子 Tab、转换输入/输出与 Markdown 代码块同步，新代码块也沿用当前状态。切换 snippet、源码/预览及放大恢复不重置，刷新后恢复关闭。示例见 [自动换行与行号测试](docs/examples/code-wrapping.md)。
- 侧边栏固定应用名称、个人收藏、全部片段入口及“文件夹”标题，只滚动标题下面的目录列表。标题右侧的图标支持“全部折叠 / 全部展开”，批量操作所有层级，不改变当前目录或片段选择。
- 点击文件夹后，右侧以浅橙色品牌符号和简短指引提示选择片段。

可复制 [Markdown 预览示例](docs/examples/markdown-preview.md) 到自己的 `snippets/` 目录查看效果。示例使用四个反引号包住 Markdown，因此可以在内部正常嵌套三个反引号的代码块。

语法高亮配色来源：[Tomorrow Theme](https://github.com/chriskempson/tomorrow-theme)。

## 测试

```bash
npm run check
npm test
npm run test:e2e
```

普通测试无需先构建。浏览器测试使用 `tests/fixtures/library/`，自动复制到 `.generated/` 的独立内容库并在测试后清理，不读取或改写个人 `snippets/`。默认测试端口为开发 5197、生产 4197，可通过 `APP_TEST_PORT` 覆盖。浏览器测试会自动启动专用服务器；使用本机 Chrome（macOS），其他环境需要先执行 `npx playwright install chromium`。

生产离线验证：

```bash
APP_TEST_MODE=production npm run test:e2e
```

生产测试会先以测试内容库构建 `dist/` 再启动预览。测试后运行 `npm run build` 即可重新生成个人内容的生产产物。生产测试需要 localhost 或 HTTPS，以注册 Service Worker。PWA 可安装到桌面或 Android；iPhone / iPad 通过浏览器“添加到主屏幕”。全部资源缓存成功后才提示“全库可离线使用”。新版本完整缓存后提示刷新，准备失败时旧版本继续可用。

## 静态构建与部署

```bash
npm run build
npm run preview
```

部署 `dist/` 目录；无需服务器端 Node.js 或数据库。有效 Markdown 在 `/raw/` 下直接输出，原文不重写。页面路由同时生成 `index.html`，可使用支持目录首页的静态托管直接打开深层链接。

站点部署在子路径时：

```bash
SITE_BASE=/snippet-manager/ npm run build
SITE_BASE=/snippet-manager/ npm run preview
```

将 `dist/` 挂载到相应子路径。基础路径同时作用于页面、Raw、图片、Manifest 和 Service Worker。文件移动或改名会改变 URL。

如果托管平台使用 SPA 回退规则，应让 `/raw/`、`/data/`、`/content-assets/`、`/assets/` 下不存在的文件返回 HTTP 404；页面导航才回退至应用 HTML。现有静态文件应优先直接响应，`version.json`、`sw.js` 建议使用重新验证缓存策略。

浏览器内的代码和 Markdown 复制来自当前内容版本；公共 Raw URL 指向站点当前发布的文件。源码已按公开访问设计。
